ElixirV4 is the fourth generation of the Elixir Community website. Its backend provides authentication, role-based access control, clubs, events and registrations, blog publishing, mentors, testimonials, and user administration.

This documentation covers the backend as currently implemented: local setup, runtime structure, authentication, the data model, and HTTP API behavior. It is for contributors maintaining the application and developers integrating with its API.

Start with the [Backend Quickstart](./getting-started/backend-quickstart.mdx) to run the backend locally. Continue with [Backend Architecture](./architecture/backend-architecture.mdx) to understand its runtime structure. Use the [API Reference](./api-reference/authentication.mdx) for exact endpoint behavior, request and response formats, and authorization requirements.

Documentation is being published in phases. Pages marked as placeholders are not yet complete; they do not establish an API contract.
